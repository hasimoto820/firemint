config/

  ローカル設定置き場（Git 対象外の秘密情報を含む）。

--------------------------------------------------------------------------------
workspaces.json
--------------------------------------------------------------------------------

  登録済みプロジェクト名簿と、ツリーに出していた接続（loadedProjectIds）、
  フォーカス中プロジェクト。アプリが自動生成・更新する。
  サービスアカウントの中身や Google refresh_token は書かない。


--------------------------------------------------------------------------------
google_oauth.json（Phase 12）
--------------------------------------------------------------------------------

  Google サインイン用 OAuth クライアント設定。自分で置く。

  例:

    {
      "clientId": "xxxx.apps.googleusercontent.com",
      "clientSecret": "GOCSPX-xxxx"
    }

  作り方:
    1. Google Cloud Console でプロジェクトを開く（FireMint 用でも可）
    2. API とサービス → 認証情報 → OAuth クライアント ID を作成
    3. アプリケーションの種類: デスクトップアプリ
    4. Client ID / Client Secret を上記 JSON に書く
    5. Cloud Resource Manager API を有効化する（プロジェクト一覧用）

  代わりに環境変数でも可:
    FIREMINT_GOOGLE_CLIENT_ID
    FIREMINT_GOOGLE_CLIENT_SECRET


--------------------------------------------------------------------------------
google_oauth_tokens.json（Phase 12）
--------------------------------------------------------------------------------

  アプリが自動保存する。refresh_token（可能なら OS 暗号化）。
  手で編集しない。


--------------------------------------------------------------------------------
google_profiles.json（Phase 12）
--------------------------------------------------------------------------------

  Google アカウントごとの取扱いプロファイル。
  切断しても残し、再ログイン時に表示名・色・read-only・最後の focus を復元する。
  アプリが自動保存する。手で編集しない。


--------------------------------------------------------------------------------
extra_ca.pem
--------------------------------------------------------------------------------

  社内プロキシ等で SSL 検証に失敗する場合に置く CA 証明書。
