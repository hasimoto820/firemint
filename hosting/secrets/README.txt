hosting/secrets/

  FireMint 紹介サイト（Firebase Hosting）専用の鍵。
  プロジェクト firemint-e801f の中だけで使う。
  Git には入れない。mintfarm など他プロジェクトの JSON は置かない。


--------------------------------------------------------------------------------
いま必要なもの
--------------------------------------------------------------------------------

  静的サイトの Hosting 公開だけなら、次のどちらか。

  A. firebase login（Google アカウント）
     手元で一度ログインすればデプロイできる。鍵ファイルは不要。

  B. このプロジェクトのサービスアカウント JSON（CI / ログインしたくないとき）
     ファイル名の例:
       firebase-adminsdk.json
     置き場:
       hosting/secrets/firebase-adminsdk.json


--------------------------------------------------------------------------------
サービスアカウントの作り方（firemint-e801f 専用）
--------------------------------------------------------------------------------

  1. Firebase Console → firemint → プロジェクトの設定 → サービスアカウント
     または Google Cloud Console → プロジェクト firemint-e801f
  2. 「新しい秘密鍵の生成」
     （既存の mintfarm 用 JSON をコピーしない）
  3. ダウンロードした JSON をこのフォルダへリネームして置く
       hosting/secrets/firebase-adminsdk.json
  4. 役割（最低限）
       Firebase Hosting 管理者
       または 編集者


--------------------------------------------------------------------------------
デプロイ（鍵ファイルを使う場合）
--------------------------------------------------------------------------------

  PowerShell:

    cd F:\FireMint\sys\firemint\hosting
    $env:GOOGLE_APPLICATION_CREDENTIALS = "$PWD\secrets\firebase-adminsdk.json"
    npm run build
    npx firebase-tools deploy --only hosting


--------------------------------------------------------------------------------
不要なもの
--------------------------------------------------------------------------------

  - コンソールの「ウェブアプリを追加」で出る apiKey
    このサイトは Firebase JS SDK を使わないので、Hosting には不要。
  - デスクトップアプリ用の接続鍵（config/ や他プロジェクトの SA）
    アプリ本体とは混ぜない。
