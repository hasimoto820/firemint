GitHub Releases で配る

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@


配布先:     https://github.com/hasimoto820/firemint-desktop
            公開のリポジトリ。README とインストーラーだけを置く。ソースは置かない。
            ソースのリポジトリ hasimoto820/firemint は非公開のまま。
            リポジトリの名前は自動アップデートの宛先としてアプリに入るので、変えない。

Mac 版:     出す時も同じリポジトリ、同じリリースに置く。
            Windows は latest.yml、Mac は latest-mac.yml を見るので混ざらない。


================================================================================
準備（一度だけ）
================================================================================


＊　トークン
    名前:     firemint-desktop-release（fine-grained personal access token）
    対象:     hasimoto820/firemint-desktop だけ
    権限:     Contents = Read and write、Metadata = Read-only
    期限:     2027-02-18
    作り直す画面: https://github.com/settings/personal-access-tokens

＊　環境変数 GH_TOKEN
    ビルドする PC の「アカウントの環境変数を編集」で、ユーザー環境変数に GH_TOKEN を入れる。
    入れた後は、ターミナルと VS Code を開き直す。
    確かめる（トークンは表示しない）:

        if ($env:GH_TOKEN) { "OK" } else { "まだ" }


================================================================================
リリースの手順
================================================================================


1.  版の番号を上げる
    package.json の "version" を書き換える（例: 1.0.0 → 1.0.1）。
    同じ番号のまま出すと、使っている人のアプリは更新に気づかない。

2.  ビルドして GitHub に上げる

        npm run release:win

    typecheck → electron-vite build → electron-builder の順に動き、
    GitHub に「下書き（Draft）」のリリース v1.0.1 ができる。
    上がるファイル:
        firemint-1.0.1-setup.exe            インストーラー
        firemint-1.0.1-setup.exe.blockmap   差分ダウンロード用
        latest.yml                          アプリが更新を確かめる時に読む

3.  下書きを公開する
    https://github.com/hasimoto820/firemint-desktop/releases を開く。
    「Draft」のリリースの鉛筆（Edit）を押す。
    説明（変わったこと）を書き、「Publish release」を押す。
    下書きのままでは、使っている人には届かない。

＊　上げずにビルドだけする時

        npm run build:win

    dist/ にインストーラーができる。GitHub には上げない。


================================================================================
自動アップデート
================================================================================


    src/main/auto_update.ts
    起動の時に GitHub の最新のリリースを確かめ、新しい版があれば裏でダウンロードする。
    入れ替えはアプリを閉じた時で、次に開いた時から新しい版になる。
    npm run dev の時は確かめない。
    結果はログに "update" のタグで出る。
    失敗しても（ネットにつながらない等）アプリはそのまま使える。

    1.0.0 より前の版（自動アップデートが入っていない版）は、自動では更新されない。


================================================================================
注意
================================================================================


＊　コード署名をしていないので、インストールの時に
    「Windows によって PC が保護されました」が出る。
    「詳細情報」→「実行」で進める。README に書いておく。
