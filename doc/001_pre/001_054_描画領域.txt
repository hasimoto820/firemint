
8. 描画領域をドラッグでサイズ変更



@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@


洗い出しは一通り。実装は分割。

1発目（本体 + 毎日触るところ）: 済み
　左サイドバー / Split 左右 / Simple・Query のテーブル↔JSON / Query エディタ高さ
　サイズはセッション限り（再起動で戻る）。サッシをダブルクリックで初期サイズ。

2発目: 済み
　AUTH 一覧↔詳細 / サイドバー内部（名簿↔ツリー） / Imp・Exp・Transport・Emulator ログ / Diff / 一括パネル / フィールド一括の中

3発目: 済み
　テーブル列幅（Simple / Query / Diff） / フィールド一括モーダルの縦横
　サイズはセッション限り。列境界・モーダルの辺をダブルクリックで初期サイズ。


8 は完了。
Query / JSON エディタの CSS resize は 1発目でやめた。AUTH claims は textarea のまま。


--------------------------------------------------------------------------------
骨格（常時）
--------------------------------------------------------------------------------

・左サイドバー ↔ メイン
　今: ドラッグで幅変更。初期 240px。min 160px

・Split 左右ペイン（View → Split View）
　今: ドラッグで左右の取り分。初期 50%。min 各 220px


--------------------------------------------------------------------------------
左サイドバー内部
--------------------------------------------------------------------------------

・プロジェクト名簿 ↔ FIRESTORE ツリー（＋ AUTH 入口）
　今: ドラッグで高さ。初期名簿 32%。min 名簿 72px / ツリー 120px
　ツリーは名簿の下のペイン（プロジェクト行の入れ子はやめた）


--------------------------------------------------------------------------------
Simple
--------------------------------------------------------------------------------

・上: ドキュメントテーブル ↔ 下: JSON パネル
　今: ドラッグで高さ。初期 JSON 38%。min 各 120px
　JSON エディタはパネルに追従（textarea の CSS resize はやめた）

・テーブル列幅
　今: ヘッダー右端をドラッグ。初期 140px。min 56px。ダブルクリックでその列だけ戻す
　列の表示・並び替え（上下ボタン）とは別

・チェック一括パネル（BulkActions）の高さ
　今: 選択時にテーブル下へ。ドラッグで高さ。初期 200px


--------------------------------------------------------------------------------
Query
--------------------------------------------------------------------------------

・Query エディタの高さ
　今: ドラッグで高さ。初期 200px。min 96px。textarea の CSS resize はやめた

・上: 結果テーブル ↔ 下: JSON パネル
　今: ドラッグで高さ。初期 JSON 36%。min 各 100px

・テーブル列幅
　Simple と同じテーブル。初期・操作も同じ


--------------------------------------------------------------------------------
AUTH
--------------------------------------------------------------------------------

・ユーザー一覧 ↔ 右の詳細
　今: ドラッグで幅。初期詳細 36%。min 一覧 260px / 詳細 240px


--------------------------------------------------------------------------------
Imp / Exp ・ Transport ・ Emulator ・ Diff
--------------------------------------------------------------------------------

・フォーム ↔ 実行ログ
　Imp/Exp / Transport / Emulator 共通。今: ドラッグで高さ。初期ログ 280px

・Diff: フォーム ↔ 結果テーブル
　今: ドラッグで高さ。初期テーブル 58%

・Diff テーブルの列幅（ID / path / 固有 / ダンプ / プロジェクト）
　今: ヘッダー右端をドラッグ。初期 88 / 220 / 96 / 180 / 180。ダブルクリックでその列だけ戻す


--------------------------------------------------------------------------------
ダイアログ
--------------------------------------------------------------------------------

・フィールド一括モーダル自体の縦横
　今: 辺・角をドラッグ。初期 560×640。min 420×360。ダブルクリックで初期サイズ
　位置は中央のまま。幅と高さだけ変える

・（中）フォーム ↔ before/after プレビュー
　今: ドラッグで高さ。初期プレビュー 42%。プレビュー前は空の案内


--------------------------------------------------------------------------------
たぶん対象外（確認）
--------------------------------------------------------------------------------

・アプリウィンドウ全体（Electron 標準）
・設定ウィンドウ（resizable 済み）
・ヘッダー / タブバーの高さ
・Command Palette
・接続ランディング
・各種ダイアログの外側サイズ（新規コレクションなど。フィールド一括だけ例外）
・JSON 内の画像プレビュー（max-height 110px）
・タブの横スクロール（分割ではない）
