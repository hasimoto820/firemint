================================================================================
目指すもの（一旦ここ）
================================================================================

  現行の FireMint 形式 JSON を、ユーザーが触るファイルとして完全廃止する。

  出す・入れる・Diff の相手は、公式のエクスポート形式。
  コンソール / gcloud / Emulator の --import と同じフォルダ。

  中でドキュメント配列に解く。ユーザーに JSON を見せない。
  見るのは Simple。


================================================================================
公式は JSON ではない
================================================================================

  ファイル名に json とあるが、公式の中身は JSON ではない。
  フォルダである。

    export-日時/
      日時.overall_export_metadata     目次
      all_namespaces/
        all_kinds/                     全部のとき
        kind_名前/                     コレクション名を指定したとき
          *.export_metadata
          output-0                     実データ（バイナリ）
          output-1

  Emulator の firebase emulators:export も中身はこれ。
  外側に firebase-export-metadata.json が 1 枚付くだけ。

  渡すときはフォルダのまま、またはフォルダを zip で 1 ファイルにする。
  zip の中は 2 枚の JSON ではない（現行のプロジェクト zip とは別物）。


================================================================================
口（UI）
================================================================================

  File → Imp/Exp のまま、口は一つ。メニューを増やさない。

  出す
    公式フォルダ（またはその zip）

  入れる
    公式フォルダ（またはその zip）を選ぶ

  Diff
    本番コレクション ↔ 公式フォルダ
    中で解いて比べる。ユーザーは JSON を選ばない。

  選ぶのはプロジェクト。コレクションの載せ替えはしない。
  書く先は、公式データが持っている path。


================================================================================
やらない（この見出しの外）
================================================================================

  □ Imp/Exp から CSV を出す
     Excel 用。要るなら Simple / Query の一覧側。後でよい。
  □ 一括操作の diff プレビュー（001_050 の 6。保留）
  □ タブグループ / 領域リサイズ / ログ / ショートカット（001_050 の 7〜10）
     公式互換の実装と同時に走らせない。


================================================================================
完全廃止の意味
================================================================================

  ユーザー向けファイルとして廃止
    { "id", "path", "data" } の JSON
    manifest.json + documents.json のプロジェクト zip

  残してよい
    実行中の内部表現（解いたあとのドキュメント配列）
    これはファイルではない。

  移行
    手元の FireMint JSON は公式へは戻せない（別形式）。
    廃止後は読まない。残したいデータは、廃止前に公式へ出し直す。


================================================================================
未決（実装前に切る）
================================================================================

  □ 出せる単位
     公式はコレクションの「名前」（グループ）。パスではない。
     FireMint の「この company/xxx の下だけ」とは違う。
     プロジェクト丸ごとか、名前指定か、を決める。

  □ Diff の単位
     解いた公式データのうち、今開いているコレクションだけ比べるか。
     グループ名だと、同じ名前のサブコレが他にも混ざる。

  □ zip で包むか、フォルダのまま出すか

  □ GCS へ直接出すか（コンソール Import はバケットを見る）。
     第一弾はローカルのフォルダ / zip でよい。
