＊　考え方
　Android と同じく、機能を選ぶと、今のタブの中身が入れ替わる。
　Android は左ツリーが無いので「戻る」で前の画面に帰るが、Windows は左ツリーから直接行けるので、
　履歴と戻るボタンは作らない。
　入力の途中を残したまま別のものを見たい時は、タブを増やす。

＊　1. どの機能を選んでも、今のタブの中身が入れ替わる
　・左ツリーのコレクション、ドキュメント、左下の AUTH
　・メニュー・コマンドパレットから開く Cloud Imp/Exp、Emulator Imp/Exp、Transport、Diff
　今のタブがツール（Imp/Exp など）でも、新しいタブにはしない。

＊　2. 入れ替えたら、前の画面の途中のものは捨てる
　・ツールの入力（ファイルの選択、保存先、検証の結果など）
　・ドキュメントの編集途中（Save していない変更）も、確認せずに捨てる
　　（捨てられるリスクより、毎回聞かれる煩わしさの方が大きいと判断した）
　ツールは、開くたびにまっさら。入力はタブごとに持つので、別のタブのツールには影響しない。
　メニューの「コレクションをエクスポート」のように、開く時に対象を渡す操作は、その対象を入れて開く。
　コレクションの表の位置とクエリは、今まで通り、同じタブでそのコレクションに戻った時に戻す（pageCache）。

＊　3. 残したい時は、新しいタブで開く
　右クリック →「新しいタブで開く」、Ctrl+クリック、ホイールクリック、＋ボタン。

＊　4. ツールの「飛ぶ」動きはしない
　別のタブに同じツールがあっても、そこへは移らない。今のタブに開く。

＊　5. 実行中のジョブは止めない
　Import / Export / 転送の途中で、タブの中身を別の画面に入れ替えても、ジョブは裏で動き続ける。
　もう一度そのツールを開けば、進み具合とログが出る。
　ツールのタブを閉じる時は、今まで通り「止めますか？」と聞く。

＊　6. 分割表示では、今触っている側が入れ替わる
　どちらの側かが分かるように、触っている側に印を付ける。
