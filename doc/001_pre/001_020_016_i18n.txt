================================================================================
目的
================================================================================

  - FireMint の UI 文言をキー化し、言語を切り替えられるようにする
  - デフォルトは英語。日本語・繁体字・簡体字を同梱する
  - いま日本語直書きの画面を、段階的に辞書へ移す


================================================================================
対応言語
================================================================================

  コード（BCP 47）   表示名（英語）              備考
  ───────────────   ───────────────────────   ────────
  en                 English                   デフォルト・正本
  ja                 Japanese
  zh-Hant            Traditional Chinese       繁体字
  zh-Hans            Simplified Chinese        簡体字

  初回:
    - 保存済み locale があればそれ
    - なければ en（OS 言語追従は後回し可。やるとしたら設定で「System」を足す）


================================================================================
非対象（16-a ではやらない）
================================================================================

  - ダークテーマ / ショートカット（Phase 16-b 以降）
  - 保存時コンフリクト検出
  - Mac / Linux ビルド
  - Phase 15 onboarding（保留のまま）
  - ログ（main の開発者向けログ）の翻訳
  - Firebase 由来の固有名詞・path・projectId・UID の翻訳
  - 外部ドキュメント全文の翻訳（必要なら別途）


================================================================================
責務分担
================================================================================

  shared/i18n/
    - locale 型・辞書（en 正本 + ja / zh-Hant / zh-Hans）
    - t(key, params?) … 文言取得
    - 欠落キーは en にフォールバック（それでも無ければ key 自体を出す）
    - React 向け: I18nProvider / useT（renderer）

  shared/settings/（最小）
    - ユーザー設定の永続化（locale など）
    - 場所: config/settings.json（workspaces.json と同様、Git 対象外）
    - getSettings / setLocale（IPC: main が読み書き）

  features/*/renderer, shared/shell, shared/ui
    - ユーザー向け文字列は t('...') 経由
    - ハードコード日本語を順次置換

  main
    - ダイアログタイトル・確認文などユーザー向けは i18n を参照できる形に
      （まず renderer 優先。main 文言は後続バッチで可）


================================================================================
辞書の形
================================================================================

  キーはドット区切りの英単語（画面・機能で束ねる）:

    connection.connect
    connection.disconnect
    workspace.projects
    explorer.firestore
    auth_users.title
    common.cancel
    common.save
    …

  ファイル例:

    shared/i18n/
      shared/
        types.ts          … Locale, MessageKey, …
        locales/
          en.ts           … 正本
          ja.ts
          zh_Hant.ts
          zh_Hans.ts
      renderer/
        I18nProvider.tsx
        use_t.ts
      main/               … 必要なら main 用 t()（後続でも可）

  パラメータ:

    t('auth_users.selected_count', { count: 3 })
    → en: "{count} selected"


================================================================================
設定 UI
================================================================================

  置き場（16-a）:
    - メニュー: Settings → Settings…（別ウィンドウ）
    - ウィンドウ内で言語を選択（en / ja / zh-Hant / zh-Hans）

  切替時:
    - settings に locale を保存
    - 全ウィンドウへ settings:changed を配信し即時反映


================================================================================
移行方針
================================================================================

  一気に全画面はやらない。優先順:

    1. 箱 + en 辞書骨格 + settings locale + 切替 UI
    2. シェル（メニュー・ヘッダー・共通ボタン）
    3. 接続（connection / list / Google）
    4. explorer / query の主要ラベル
    5. auth_users / data_transfer / bulk
    6. 残り（エラー文言・confirm）

  未移行の日本語が残っても起動は可。
  新規 UI は最初から t() 必須。
