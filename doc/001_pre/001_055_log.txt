
9. ログ



@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@


方針決定。実装はこれから。

「ログ」は3種類に分かれる。9 番でやるのは下の2本だけ。

1. アプリログ … 開発者・問い合わせ用（接続失敗、Firestore エラー、起動情報）
2. 操作ログ … ユーザー向け（Imp/Exp / Transport / Emulator 等の長い処理）
3. 監査ログ … 誰がいつ何を変更したか → 対象外（後回し）


--------------------------------------------------------------------------------
置き場所（共通）
--------------------------------------------------------------------------------

Electron の userData 配下。

　<userData>/logs/

Windows の例:

　C:\Users\<ユーザー>\AppData\Roaming\FireMint\logs\

macOS:

　~/Library/Application Support/FireMint/logs/

ユーザーが探すとき、末尾が **FireMint/** になること。
dev / 本番でフォルダ名がズレないよう、productName 等も FireMint に揃える
（現状 electron-builder.yml は react-ts のまま → 要修正）。


--------------------------------------------------------------------------------
ファイル（同じ logs/ 階層・名前で分ける）
--------------------------------------------------------------------------------

　firemint_app_YYYY-MM-DD.log … アプリログ（shared/logging/logger.ts から追記）
　firemint_job_YYYY-MM-DD.log … 操作ログ（Imp/Exp / Transport / Emulator / Script 等）

同じフォルダ・別プレフィックス。サブフォルダには分けない。

サイズ上限を超えた同日分:

　firemint_app_2026-08-27.log
　firemint_app_2026-08-27_2.log
　firemint_app_2026-08-27_3.log
　（job も同じ）

console への出力は今どおり残してよい（dev 用）。
ファイルは問い合わせ・事後確認用。


--------------------------------------------------------------------------------
ローテーション / 保持
--------------------------------------------------------------------------------

・1日1ファイル（日付はローカル日付）
・ファイルサイズ上限 5 MB。超えたら同日の続き（_2, _3 …）を新規作成
・14日より古い firemint_app_* / firemint_job_* は削除（起動時などで掃除）
・圧縮（gzip 等）は無し


--------------------------------------------------------------------------------
1. アプリログ（firemint_app_*）
--------------------------------------------------------------------------------

・今: logInfo / logWarn / logError → console のみ
・やる: 上記 logger から firemint_app_YYYY-MM-DD.log にも追記
・形式: 既存どおり `[firemint:<tag>] message` + detail
・console 直叩き（env.ts 等）は logger に寄せる（薄く）

今はやらない:
　アプリ内ログビューア
　settings の logLevel 切替


--------------------------------------------------------------------------------
2. 操作ログ（firemint_job_* + 画面下部）
--------------------------------------------------------------------------------

・今: Imp/Exp / Transport / Emulator 画面下部にジョブログ（UI）
　進捗バーと短文。詳細は足りないことがある
・やる:
　- 画面と firemint_job_* の両方に同じ内容を出す（または UI はファイル tail でも可。まずは二重出力でよい）
　- 進捗（何件目 / 全体）
　- 失敗 path と理由
　- 完了サマリ（成功 N / 失敗 M / スキップ K）
　- 長いログの「コピー」「保存」は後からでも可。最低 firemint_job_* に残る

対象（長い処理）:
　Imp/Exp / Transport / Emulator / Script runner
　Diff は短いことが多い → 必要なら同じ仕組みに載せる

開発者向け firemint_app_* とは混ぜない。


--------------------------------------------------------------------------------
UI（最小）
--------------------------------------------------------------------------------

・Help または設定に「ログフォルダを開く」1 項目
　shell.openPath(<userData>/logs) 相当
・アプリ内でログを全文表示する画面は作らない（今回）


--------------------------------------------------------------------------------
対象外
--------------------------------------------------------------------------------

・操作監査ログ（変更履歴の永続）
・main ログの i18n（001_020_016）
・ジョブログパネルのレイアウト変更（001_054 で分割済み。高さは触らない）
・圧縮（gzip 等）


--------------------------------------------------------------------------------
実装の順（案）
--------------------------------------------------------------------------------

1発目: logs/ 作成 + firemint_app_* 追記（日次・5MB・14日削除）+ logger 寄せ + ログフォルダを開く
2発目: 操作ログを firemint_job_* に出す + 画面下部の詳細度アップ（Imp/Exp から）


--------------------------------------------------------------------------------
今ある / これから
--------------------------------------------------------------------------------

今:
　shared/logging/logger.ts（console）
　Imp/Exp 等の画面下部ジョブログ（UI のみ）
　001_054: フォーム ↔ ログの高さドラッグ済み

これから:
　FireMint/logs/firemint_app_YYYY-MM-DD.log（+_2 …）
　FireMint/logs/firemint_job_YYYY-MM-DD.log（+_2 …）
　14日より古いファイルを削除
　ログフォルダを開く
