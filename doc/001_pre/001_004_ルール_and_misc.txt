＊　ハイフン禁止。アンスコで統一。

＊　Firestore 接続ルール（必須）
    - admin.firestore() 直叩き禁止
    - 必ず shared/firestore/client.ts 経由
    - initializeFirestore(app, { preferRest: true }) は client.ts のみ
    背景:
      - gRPC 通信は Node + firebase-admin でハングしやすい → REST 優先
      - Node は Windows CA を自動信頼しない → main/env.ts で win-ca
      - dev / プロダクト版の両方で必要
      - gRPC　→　REST


＊　UI部品化
Page → 必ず features/*/renderer/ui/
部品（名前付き React コンポーネントで再利用）→ shared/ui/
生 HTML → 包まない。必要なら Button 程度
迷ったら → 2 feature から使う？ Yes → shared / No → feature


＊　ヘッダーメニューの直下のエリアの扱い
    画面は大きな塊（エリア）に分ける。ショートカットはエリアへ着地する。
    CRUD はキーにしない。着地後の Tab はエリア内だけ（一周）。
    詳細: 001_056_shortcut.txt
