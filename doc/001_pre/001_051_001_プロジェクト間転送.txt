--------------------------------------------------------------------------------
何をするものか
--------------------------------------------------------------------------------

  つながっているプロジェクト同士で、データをコピーする。
  ファイルを人手で経由しない。

  今でも、一方からエクスポートして、もう一方にインポートすれば移せる。
  本項目は、その一手間を減らすため。


--------------------------------------------------------------------------------
17-c との関係
--------------------------------------------------------------------------------

  公式 emulator export 形式と、Emulator 同期（17-c）は、本項目と同時に設計する。
  データの移動と Emulator の両方が乗る話。今の zip / json の Imp/Exp とは別件。

--------------------------------------------------------------------------------
コピー元 / コピー先（決定）
--------------------------------------------------------------------------------

  コピー元は、左ツリーの選択。
  画面でコピー元をもう一度選ばせない。
  「コピー元は今選んでいるこれ」と出す。

  クラウド → トランスポート から開く
    コピー元はクラウドのプロジェクト（左ツリーで選択中）。
    左ツリーがエミュレーターなら、このメニューは disable。

  エミュレーター → トランスポート から開く
    コピー元はエミュレーターのプロジェクト（左ツリーで選択中）。
    左ツリーがクラウドなら、このメニューは disable。

  コピー先は、画面の中で選ぶ。クラウドでもエミュレーターでもよい。
  コピー元と同じプロジェクトは不可。


--------------------------------------------------------------------------------
プロジェクト / コレクション（決定）
--------------------------------------------------------------------------------

  コレクション
    コピーするのは、左ツリーで選んでいるそのコレクション。
    コピー先は、別プロジェクトと、そのコレクション。

  プロジェクト
    コピーするのは、左ツリーで選んでいるそのプロジェクトの中身。
    コピー先は、別プロジェクト。
    Firestore に「プロジェクトの中にプロジェクト」は無い。
    増えるのは、コピー先のルートコレクション。

    コピー元 A: col1A, col2A
    コピー先 B: col1B, col2B
    終わったあとの B:
      col1A
      col2A
      col1B
      col2B


--------------------------------------------------------------------------------
衝突（決定）
--------------------------------------------------------------------------------

  衝突は、同じコレクションの同じドキュメント id。
  コレクション名が同じでも、ドキュメント id が被らなければ足す。

  ファイルのインポート（現状。本項目の方針とは別）
    検証が先。実行の直前にもう一度見る。
    id 付きは 1 件ずつ get。衝突 5 件で打ち切り。
    衝突したら書込ゼロ。上書きしない。
    検証をやめるのは将来。

  トランスポート
    検証ボタンを押さなくても、実行できる。
    検証は任意。したい人は先に検証する。
    実行中に衝突したら、そのドキュメントはスキップして先に進む。
    全部は止めない。
