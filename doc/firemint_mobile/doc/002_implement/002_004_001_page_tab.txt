================================================================================
概要
================================================================================


＊　複数ページを保持するタブ制の導入
＊　現状のホームからスタートする構造との折衝







================================================================================
UI
================================================================================



アプリ起動時、現在のホームページ（ルート頁）からスタート

ヘッダー右側に、
＋
タブ
ボタンを設置




タブボタン：
・作成済のページの一覧、
・タップでアクティブ（前面に出す）又は、削除









================================================================================
詳細
================================================================================



・ホーム画面から始める機能を一頁として保持。
・潜った後も、戻るボタンで、状態を保持し続ける。
・ドキュメント詳細へ移る際は、"別タブで開く"を可能にする。

・　＋ボタンが押された段階で、新ページを作成。

・　左上をタップで、トップに向かって上がっていくが、この遷移を続ける限りは、同一ページを使った状態。













================================================================================
ディレクトリ構成
================================================================================


タブは基盤。feature を増やさない。
画面本体は今の app / features/*/ui のまま。枠だけ shared/shell。
画面の本体を shared/ui に置かない。
001_003 の shared/shell（タブ枠）をここで埋める。


src/
  app/
    App.tsx                         … タブを持つ。前面のページだけ出す
    HomeScreen.tsx                  … 起動のルート頁。カードは今のページで潜る

  shared/
    shell/
      tabs.ts                       … 型（ページ、その中のスタック）
      chrome.tsx                    … 右上 ＋ / タブ
      TabListScreen.tsx             … 作成済の一覧。前面に出す / 削除

  features/
    explorer/ui/                    … 既存。潜る先。タブは知らない
    workspace/ui/
    snippet/ui/


android/ は足さない。タブはプロセス内の状態。再起動では残さない。
