================================================================================
スニペット
================================================================================

＊　スニペットの一覧ページは２種類。

ホーム画面に設置されたスニペットボタンから進む：
・crud機能付きのスニペット一覧ページ
・このページからのスニペット選択は、クリップボードに入るのみ

プロジェクト、コレクション、ドキュメントなど、他機能のページ内にあるスニペットボタン
・crud機能無のスニペット一覧ページ
・このページからのスニペット選択は、状況により変化する。
・・カーソルが、テキストエリア内：テキストエリアに即張り付け。　＋　クリップボードに入る
・・カーソルが、テキストエリア外：クリップボードに入るのみ



＊　スニペットのコピーの手順

・一覧ページでタップをすると、ポップアップで、長文スニペットに対応できる全文表示画面になる。
・この画面のボタンは２種類　戻る　コピー
queryの全文を確認したいだろうから、全文表示を挟みたい。

＊　エイリアス( name )を可能に
長文のqueryが一覧に並ぶことを想像し、なので、スニペットの全文を一覧画面に表示できないと想定する。
その上で、エイリアスを可能にする。
エイリアスが無いレコードは、一覧に本文をできるだけ表示する。


＊　グループ
スニペットの管理単位はプロジェクトではない。スニペット専用のグループ。
階層は一段。グループの中にグループは置かない。

ルートに、スニペット単体とグループが並ぶ。



================================================================================
UI
================================================================================


ドキュメント一覧画面


基本構造として、ヘッダー部、メイン部

ヘッダー部：
・simple/query
・current collection / collection group
・検索条件（フィールド選択・演算子選択・値用テキストボックス）
・ヒット件数
・開閉式とする


メイン部：
・検索結果のドキュメント、各レコードを表示
・ページング（一頁最大２０件）。　<<, <, >, >>　且、ページ番号も指定可能に。
・各ドキュメントをタップで、ドキュメント詳細画面へ遷移






================================================================================
ディレクトリ構成
================================================================================


query の実行は features/query。スニペットは features/snippet。
ドキュメント一覧のページは explorer のまま。ヘッダー部品だけ query から載せる。
画面の本体を shared/ui に置かない。


src/
  app/
    App.tsx                         … ホーム → スニペット一覧のルート
    HomeScreen.tsx                  … スニペットカード

  features/
    explorer/
      ui/
        DocumentListScreen.tsx      … 既存。開閉ヘッダー＋結果一覧

    query/
      ui/
        components/                 … 開閉ヘッダー、simple 条件、query の JS
      native/
        query.ts                    … Run / 件数（RN → Kotlin）
      shared/
        query.ts                    … 型（条件、結果）

    snippet/
      ui/
        SnippetListScreen.tsx       … ホームから。CRUD あり
        SnippetPickScreen.tsx       … 他画面から。CRUD なし
        SnippetPreviewScreen.tsx    … 全文表示。戻る / コピー
      native/
        snippets.ts                 … 口（RN → SQLite）
      shared/
        snippet.ts                  … 型（name、本文、グループ）

  shared/
    safety/confirm_write.ts         … 既存。JS の書き込み確認


android/
  query/                            … 論理の箱。中身は置かない
  snippet/                          … 論理の箱。中身は置かない
  app/src/main/java/com/firemint/
    query/
      QueryModule.kt                … Run、条件、Collection Group、全件数
      QueryPackage.kt
    snippet/
      SnippetModule.kt
      SnippetPackage.kt
      SnippetDb.kt                  … SQLite
    shared/
      FirestoreClient.kt            … 既存。初期化はここだけ


kotlin の置き場は java/ だが、中身は .kt。
