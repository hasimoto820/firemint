
FireMint_M 計画

@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@@

■ プロダクト概要
  Firestore 外部管理デスクトップモバイル/android先行。
  公式コンソールの不足（一括検索・一括更新など）を補う。
  Firefoo 系の後発。価格はやや安く、使いやすさで差別化。
  デスクトップツールFireMint(doc\firemint_desktop\ 以下)の兄弟プロジェクト
  機能を制限して、モバイルアプリとして作り直し。



================================================================================
技術選定
================================================================================

【採用】React Native + TypeScript + Kotlin
  (Android の橋は Kotlin。)

【不採用 / デスクトップFireMintとの対比】
  Electron / Capacitor     デスクトップの延長。携帯では使わない
  firebase-admin           Node 専用。端末に置かない
  Compose で画面を二重     画面は RN のみ。Kotlin は橋


--------------------------------------------------------------------------------
スタック
--------------------------------------------------------------------------------

  レイヤー          技術
  ─────────────────────────────────────────
  UI                React Native + TypeScript
  Android の橋      Kotlin（サインイン、公式 SDK、ファイル）
  Firestore         公式 Android SDK または REST（Kotlin 経由）
  クエリエディタ    RN。JS を書いて Run。Firestore の実処理は Kotlin 経由
  接続              Google サインイン（IAM のあるアカウント）
  対象              MVP: Android → iOS は後で判断

  アーキテクチャ:

    React Native (TypeScript)
        ├── 画面
        └── クエリエディタ（JS を書いて Run）
                │
                ▼
    Kotlin (Android)
        ├── Google サインイン
        └── Firestore SDK / REST


--------------------------------------------------------------------------------
Kotlin を足す理由
--------------------------------------------------------------------------------

  1. Google サインインと公式 SDK は JS だけでは足りない
  2. サービスアカウント JSON(鍵ファイル) は端末に置かない
