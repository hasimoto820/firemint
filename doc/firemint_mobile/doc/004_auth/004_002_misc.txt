＊　最終ログインの表示
    API が返す lastLoginAt（ミリ秒の数字の文字列）を、変換せずに出している。
    一覧の「最終ログイン」と、書き出しの CSV / JSON に、数字がそのまま出ている可能性が高い。
    createdAt も同じ。
      IdentityToolkitClient.kt  toUser
      AuthUsersListScreen.tsx   行の表示 / usersToCsv

    → OK
        Kotlin で、ISO 8601 の UTC（例 2026-09-10T03:12:45Z）に直す。書き出しは、この形のまま。
        一覧は、端末のタイムゾーンで「2026-09-10 12:12」の形。




＊　項目を空にする編集
    displayName や phoneNumber を消して保存しても、消えないはず。エラーも出ない。
    API に削除の指定（deleteAttribute / deleteProvider）を送っていないため。
    phoneNumber は、空の時は送らない作りになっている。
      IdentityToolkitClient.kt  updateAccount

    → OK
        displayName が空 → deleteAttribute: DISPLAY_NAME を送る。
        phoneNumber が空 → deleteProvider: phone を送る。
        email は、消す手段が無い。空にして保存すると、「メールアドレスは空にできません」と
        出して止める（もともと email が無いユーザーは、空のまま保存できる）。




＊　書き出しの保存先
    仕様は「既定の保存フォルダ + 任意で保存先を選べる」（002_006_001「書き出し」）。
    実装は、毎回、保存先を選ぶ方式だけ。
      AuthUsersListScreen.tsx   onExport

    →　今のままでよい（決定）。押すたびに、端末のファイル選択の画面が開き、保存先を選べる。
        コードは変えない。仕様（002_006_001「書き出し」）の方を、実装に合わせた。


＊　デバッグ表示
    Identity Toolkit API が無効な時の画面に、「デバッグ用(実際のエラー全文)」が出たまま。
      AuthUsersListScreen.tsx   auth.users.debugLabel

    → OK
        見出しと、projectId・エラー全文の表示を消した。文言（4言語）も消した。
        「有効化する」と、ブラウザを開くリンクは、そのまま。
        画面では未確認（API が無効な状態を、作れなかった。004_005_google審査.txt「未決」）。




＊　「続きを読む」のトークン
    一覧を開いて 50 分以上たってから押すと、権限エラーになる。
    最初の読み込みは ensureAuthUsersAccess を通すが、続きの読み込みは通さないため。
      AuthUsersListScreen.tsx   loadMore

    →　対応済み。実機では未確認。
        loadMore でも、ensureAuthUsersAccess を通す。期限が切れていれば、裏で取り直す。
        Google の許可画面をキャンセルした時は、エラーを出さずに戻る。
        起きる条件は狭い（ユーザーが100人を超えるプロジェクトで、一覧を開いたまま
        50分以上たち、その直後に「続きを読む」を押した時だけ）。




＊　削除・保存の後、一覧が古いまま
    詳細でユーザーを削除して一覧に戻ると、削除したユーザーが、まだ並んでいる（実機で確認）。
    保存・無効化/有効化の後も、一覧は古い値のまま。
    一覧は、詳細を開いている間も裏で開いたままで、戻った時に読み直さないため。
      App.tsx                   onDeleted={pop}
      AuthUsersListScreen.tsx

    →　対応済み。実機では未確認。
        読み直さずに、一覧の該当ユーザーの行だけを合わせる（削除なら、行を消す）。
        スクロール位置と、「続きを読む」で読んだ分は残る。
        仕様（002_006_001「削除後は一覧に戻り、再読み込みする」）も、これに合わせた。
          native/auth_users.ts      onAuthUserChange（保存・無効化/有効化・削除で知らせる）
          AuthUsersListScreen.tsx   知らせを受けて、行を差し替える
